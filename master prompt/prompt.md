# Definición

este proyecto estara orientado a estudiantes de la UPB, donde podran agendar clases con tutores, tener una base de datos de conocimiento según su carrera y poder consultar cada sección en un apartado de clases.

# Alcance

Este desarrollo debe ser unicamente llevado a un bosquejo, osea que sea un visual para el cliente, junto con implementaciones basicas de funcionamiento, no debe existir ni un servidor ni una base de datos, los datos los manejaremos con un JSON el cual mutaremos según lo que haga el cliente en el sistema y se almacenara como una cookie en el navegador, esto con el fin de que si se reinicia la pagina no se reseteara todo, el JSON tambien debe contar con un usuario de prueba para simular un login y register.

# Tech utilizada

Procura utilizar Angular con TS, revisa las skills que tienes disponibles para disponer de buenos patrones de diseño en el desarrollo de la pagina ademas de tambien contar con habilidades de frontend.
